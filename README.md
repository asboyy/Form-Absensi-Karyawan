# Form Absensi Karyawan

Form Absensi Karyawan adalah aplikasi desktop berbasis Visual Basic .NET yang dirancang untuk mendigitalisasi proses pencatatan kehadiran di lingkungan kerja. Proyek ini berfokus pada kemudahan pengisian data (data entry) dan validasi kehadiran guna memastikan akurasi laporan kedisiplinan karyawan.

## 🌟 Fitur Utama

- **Pencatatan Jam Kehadiran:** Fitur input untuk jam masuk, jam pulang, dan status kehadiran (Hadir, Izin, Sakit, Alpa).
- **Validasi Data Karyawan:** Memastikan data yang dimasukkan sesuai dengan identitas karyawan yang terdaftar (Nama/ID).
- **Antarmuka Form yang Bersih:** Desain GUI yang dirancang agar mudah digunakan oleh operator atau karyawan secara langsung.
- **Penyimpanan Data Terstruktur:** Data absensi dikelola sedemikian rupa agar siap untuk diolah menjadi laporan bulanan.
- **Fitur Reset & Simpan:** Tombol kendali untuk menghapus inputan yang salah atau menyimpan data secara instan.

## 🛠️ Teknologi yang Digunakan

- **Bahasa Pemrograman:** Visual Basic .NET (VB.NET)
- **Framework:** .NET Framework
- **IDE:** Visual Studio
